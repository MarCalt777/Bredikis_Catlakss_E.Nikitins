# Videospēļu vēsture

## 1. Projekta apraksts

Projekts ir izstrādāts izmantojot HTML5, CSS3 un JavaScript. Projekta mērķis ir izveidot interaktīvu un responsīvu tīmekļa vietni par videospēlēm un spēļu ierīcēm no gadiem atpakaļ

- **Izstādes tēma**: videospēļu vēsture
- **Izstādes nosaukums**: Level Up

## 2. Komandas dalībnieki

1. Kristers Brēdiķis
2. Endijs Ņikitins
3. Mārcis Catlakšs

## 3. Izmantotās tehnoloģijas

- HTML5 – vietnes struktūru izveide
- CSS3 – vietnes dizains, Box Model, Flexbox/Grid un responsīvs izskārtojums
- JavaScript – interaktīvu funkciju un attēlu karuseļa izveide
- GitHub – failu versiju kontrolei un komandas sadarbība

## 4. Tīmekļa vietnes funkcionalitāte

Sākumā ir īss izstādes apraksts un laika līnija ar astoņiem notikumiem. Galerijā ir 11 eksponāti. Tos var atlasīt pēc laikmeta, un bildes var atvērt lielākā izmērā.

Karuselī ir 6 attēli. Tos var pārslēgt ar pogām vai tastatūras bultiņām. Automātiskā pārslēgšana notiek ik pēc 5,5 sekundēm. To var apturēt un atkal ieslēgt. Lapas beigās ir avoti un informācija par komandu.

## 5. Projekta palaišana

1. Lejupielādējiet projekta failus vai klonējiet GitHub repozitoriju.
2. Atveriet projekta mapi.
3. Atveriet index.html pārlūkprogrammā.
4. Pārbaudiet navigāciju, galeriju un karuseli.

Internets vajadzīgs tikai avotu saitēm.

## 6. Projekta izstrādes ieguldījums

- Kristers Brēdiķis - Uztaisija JavaScript funkcionalitāti saitei, kā arī palīdzēja ar saites dizainu
- Endijs Ņikitins - Saites dizains ar HTML un CSS
- Mārcis Catlakšs - Palīdzēja ar saites dizainu un atrada attēlus ko rādīt saitē
